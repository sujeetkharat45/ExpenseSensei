# Expense Sensei 💰
**AI-Powered Smart Expense Tracker**

Expense Sensei is a full-stack mobile and web application designed to help users track, manage, and optimize their daily expenses. This project was developed as part of the **Final Year Computer Engineering** curriculum at **CSMIT**.

## 🚀 Features
* **Real-time Tracking:** Log and categorize expenses instantly.
* **AI Insights:** Smart analysis of spending patterns.
* **Goal Tracking:** Set and monitor financial savings goals.
* **Email Reports:** Automated monthly spending reports sent via Nodemailer.
* **Responsive UI:** Built with React Native and Tailwind CSS.

## 🛠️ Tech Stack
* **Frontend:** React Native (Expo), Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB Atlas (MERN Stack)
* **Authentication:** JWT (JSON Web Tokens)
* **Mailing:** Nodemailer (Gmail SMTP)
